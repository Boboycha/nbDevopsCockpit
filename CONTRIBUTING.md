# Contributing

Issues and pull requests are welcome. Keep changes focused, preserve existing
Delphi source encoding and line endings, and include verification appropriate
to the affected platforms.

By submitting a contribution, you agree that your contribution is licensed
under the Mozilla Public License 2.0 and confirm that you have the right to
submit it. Third-party code must include its original license, copyright
notice, source URL and version or commit.

Do not include credentials, private infrastructure details, generated build
output or proprietary SDK files.
